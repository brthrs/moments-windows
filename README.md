# Moments for Windows

Installers and the auto-update feed for **Moments for Windows**. The source lives in a private repository; this repo only holds releases.

**Download:** [latest release](https://github.com/brthrs/moments-windows/releases/latest). Pick `Moments_<version>_x64-setup.exe` (installs for your user, no admin rights needed).

The app checks `releases/latest/download/latest.json` and updates itself. Updates are signed; the app refuses any it cannot verify.
